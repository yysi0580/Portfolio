ADHD Todo

ADHD Todo는 사용자가 할 일을 완벽히 정리하지 않아도, 정리되지 않은 생각을 Brain Dump로 받아 작은 실행 후보로 나누고 선택 가능한 행동으로 이어주는 실행 보조 앱입니다. 핵심은 사용자를 평가하지 않고, 사용자가 바로 고를 수 있는 작은 행동 단위로 부담을 낮추는 것입니다.

01

문제 정의

일반 투두앱은 사용자가 스스로 일을 정리하고 우선순위를 판단할 수 있다고 가정합니다. ADHD Todo는 이 전제 자체를 낮추는 방향으로 설계했습니다.

기존 투두앱의 부담

할 일을 쓰는 순간부터 제목, 우선순위, 날짜, 반복 여부를 정해야 하면 사용자는 실행 전에 계획 단계에서 먼저 지치게 됩니다.

Brain Dump 중심 입력

사용자는 정리된 할 일 대신 떠오르는 생각을 그대로 입력합니다. 시스템은 이 원문을 저장하고 작은 행동 후보로 나누는 역할을 맡습니다.

평가 없는 반응 데이터

완료하지 못한 행동을 실패로 보여주지 않고, do, snooze, pass, make_smaller 같은 반응을 다음 제안 조절용 데이터로만 사용합니다.

02

핵심 흐름

앱의 기본 흐름은 Brain Dump, Suggestions, Feedback, Action으로 이어집니다. 사용자는 정리보다 선택에 집중합니다.

1. Brain Dump

사용자가 해야 할 일을 문장 그대로 입력하면 원본 텍스트를 저장하고 세션과 연결합니다.

2. Suggestions

입력 문장을 rule-based 로직 또는 AI generator로 분석해 2~5분 단위의 작은 행동 후보로 나눕니다.

3. Feedback

사용자는 do, snooze, pass, make_smaller, capture_only 중 하나로 반응합니다. 이 반응은 성공/실패 판단이 아니라 다음 제안을 조절하는 신호입니다.

4. Action

do를 선택하면 suggestion이 active action으로 전환되고, complete 또는 abort로 종료됩니다.

반복 사용 시나리오

  • Brain Dump를 여러 번 입력해도 session과 suggestions가 섞이지 않도록 관리
  • 부담스러운 suggestion은 make_smaller로 더 작은 행동 후보로 재생성
  • 완료된 action은 다시 완료하거나 중단할 수 없도록 상태 전이 제한
  • History에서 세션, 입력, 실행, 반응 흐름을 다시 확인

03

백엔드 구현 포인트

단순 CRUD보다 사용자 흐름이 끊기지 않도록 인증, 상태 전이, AI fallback, 운영 제한을 함께 설계했습니다.

인증과 사용자 보호

회원가입, 로그인, access token, refresh token, 내 정보 조회와 수정, 비밀번호 변경 흐름을 구성했습니다. 주요 리소스는 user_id 기준으로 보호합니다.

도메인 분리

session, brain dump, suggestion, feedback, action, routine, history를 분리해 입력부터 실행까지의 흐름을 추적 가능하게 만들었습니다.

AI fallback

OpenAI API 오류, timeout, invalid structured output, 비용 제한 상황에서도 rule-based generator로 fallback해 사용자의 흐름이 끊기지 않도록 했습니다.

04

운영 안정 장치

포트폴리오 시연용 프로젝트라도 실제 운영을 고려해 인증, 제한, 비용 통제 기준을 넣었습니다.

Login Protection

비밀번호 정책과 로그인 실패 차단을 적용해 기본 인증 보안을 강화했습니다.

Rate Limit

로그인과 Brain Dump, AI 호출에 제한을 두어 반복 요청으로 인한 리스크를 낮췄습니다.

AI Cost Control

AI cache, 사용자별/전체 호출 제한, 비용 제한, usage log를 통해 API 비용을 추적할 수 있게 했습니다.

Production Guard

운영 환경에서 기본 secret이나 과도하게 열린 CORS 설정을 그대로 쓰지 못하도록 보호했습니다.
